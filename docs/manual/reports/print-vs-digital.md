# Print or send

## What it's for

A released report comes as two kinds of PDF: one to print on the branch's printer and one
to send to the patient or the doctor. Both carry exactly what was released.

## Where to find it

On a report's own screen (see [Handing over reports](delivery.md)), under **Download or
print**.

## Steps

1. Choose the paper, the reference interval column and the tests, if you need something
   other than the usual copy (see [Report options](options.md)).
2. If money is due on the bill, tick **Go ahead although ₹… is due**.
3. Press one of:
    - **PDF to print**: for the branch printer. It follows **What the Print button makes**
      in [Settings](../admin/settings.md): either without the letterhead, for paper that
      already has it printed, or with it. The printer offset is applied.
    - **PDF to send**: with the letterhead, to email or send on WhatsApp.
4. The PDF opens in a new tab. Print it from there, or save it.

## Good to know

- **PDF to send** with the usual choices is the copy stored at release, byte for byte. Any
  other copy is made again from what was released, on the letterhead the report was
  released with, so it says the same thing even if the letterhead or the catalog has
  changed since.
- Every copy is logged on the report's screen, with what was due on the bill then.
- If you forget the dues tick, the new tab shows the report's screen with "Money is still
  due on the bill"; tick the box and press the button again.
- An older version can still be printed or downloaded, to see what was handed over before;
  it carries its own version number on every page.
