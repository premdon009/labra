# Report options

## What it's for

The same choices apply to the preview a signatory opens before releasing, and to every copy
of a released report: the paper size, whether the reference interval column is shown, and
which tests are on the copy.

## Where to find it

- Before release: **Preview** on a visit's release screen (see [Releasing
  reports](releasing.md)).
- After release: **Download or print** on the report's own screen (see [Print or
  send](print-vs-digital.md)).

## Steps

1. **Paper**: A4 or A5.
2. **Reference interval column**: **Show** or **Hide**.
3. **Tests**: tick the ones you want on this copy. None ticked, or all of them, means the
   whole report.
4. Press **Open the preview**, **PDF to print** or **PDF to send**.

## Good to know

- The choices start from how the stored copy was made: A4, and the reference column as
  **Reference interval column on reports** in [Settings](../admin/settings.md) said at the
  time of release.
- A copy of only some tests says "Selected tests only: 1 of 3 on this report" on its first
  page, so nobody takes it for the whole report. It keeps the report's number and version.
- A5 always uses the plain header with the lab name and address, inside smaller margins.
- The method printed for each test is the one chosen on the result grid in the lab (see
  [Entering results](../lab/entering-results.md)); it can't be changed on a copy.
