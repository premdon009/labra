# Help and the manual

## What it's for

This manual is inside Labra, so help works even when the lab's internet is down. Each screen
opens its own page, and the whole manual can be printed as one PDF for training.

## Where to find it

- **Help** at the top of every screen, or **Alt+H**, opens the page for that screen in a new
  tab. The sign-in screen has it too.
- **Help ▸ User manual** (the link at the top of any manual page) lists every page.
- Anyone can open the manual, signed in or not. It holds no lab data.

## Steps

### Reading the help for a screen

1. On the screen you need help with, select **Help** or press **Alt+H**.
2. Read the page in the new tab, then close it to go back to your work.

### Printing the whole manual

1. Open any manual page and select **User manual** at the top.
2. Select **Download the whole manual (PDF)**.
3. Print it, or keep it on a training PC. It starts with a contents list and has one
   section per screen.

## Good to know

- The manual matches the Labra version on the server. After an upgrade, download the PDF
  again.
- Links to the runbooks and the developer pages open the Labra website, which needs the
  internet.
