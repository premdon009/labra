# Labra

Open-source software (MIT) for small Indian diagnostic lab chains: patients, visits,
billing, samples, in-house and outsourced tests, results and reports. One main lab and a few
collection centres, running on a small server at the main lab.

Labra is in early development. Nothing here is ready for a live lab yet.
