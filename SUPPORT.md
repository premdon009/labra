# Getting help

- **How do I…?** Check the user manual (`docs/manual/`) first, then ask in GitHub Discussions.
- **Something is broken:** open an issue with the bug form. Include the version from `Admin ▸ System` and the error reference number shown on the error page. Never include patient data.
- **Security problem:** follow [`SECURITY.md`](SECURITY.md), not the issue tracker.

Labra is volunteer-maintained and has no paid support or response-time promise for questions and bugs.
